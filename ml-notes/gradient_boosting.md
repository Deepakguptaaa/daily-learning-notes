# Gradient Boosting

## What is Gradient Boosting?

Gradient Boosting is an ensemble learning algorithm that builds multiple decision trees sequentially.

Each new tree tries to correct the errors made by the previous trees, resulting in a more accurate model.

## How Gradient Boosting Works

1. Train a simple decision tree.
2. Calculate prediction errors.
3. Train another tree to reduce those errors.
4. Repeat until the desired number of trees is created.
5. Combine all trees to make the final prediction.

## Advantages

* High prediction accuracy
* Handles complex datasets
* Works well for both classification and regression
* Reduces bias and variance

## Limitations

* Slower training compared to Random Forest
* Sensitive to hyperparameters
* Can overfit if not tuned properly

## Applications

* Fraud detection
* Customer churn prediction
* Medical diagnosis
* Credit scoring

## What I Learned

* Gradient Boosting builds trees sequentially.
* Each tree learns from previous mistakes.
* It often achieves better accuracy than a single decision tree.
