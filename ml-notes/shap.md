# SHAP (SHapley Additive exPlanations)

## What is SHAP?

SHAP (SHapley Additive exPlanations) is a model explainability technique used to understand how each feature contributes to a machine learning model's prediction.

It is based on Shapley values from game theory.

## Why Use SHAP?

* Explains individual predictions
* Shows feature importance
* Builds trust in AI systems
* Helps debug machine learning models

## How SHAP Works

1. Train a machine learning model.
2. Calculate the contribution of each feature.
3. Assign a SHAP value to every feature.
4. Visualize the impact on predictions.

## Advantages

* Model-agnostic
* Easy to interpret
* Supports local and global explanations
* Widely used in production ML

## Applications

* Healthcare diagnosis
* Loan approval systems
* Fraud detection
* Customer churn prediction
