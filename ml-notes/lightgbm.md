# LightGBM

## What is LightGBM?

LightGBM (Light Gradient Boosting Machine) is a gradient boosting framework developed by Microsoft. It is designed for high performance, fast training, and efficient memory usage.

## How LightGBM Works

LightGBM grows trees leaf-wise instead of level-wise, allowing it to reduce loss more efficiently and often achieve better accuracy.

## Advantages

* Faster training than many boosting algorithms
* Lower memory usage
* Handles large datasets efficiently
* Supports parallel and GPU training

## Limitations

* Can overfit on small datasets
* Requires careful hyperparameter tuning

## Applications

* Customer churn prediction
* Credit scoring
* Fraud detection
* Recommendation systems
* Sales forecasting
