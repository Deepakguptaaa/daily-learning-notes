# Machine Learning Pipeline

## What is a Machine Learning Pipeline?

A Machine Learning Pipeline is a sequence of steps used to build, train, evaluate, and deploy a machine learning model.

Pipelines help automate repetitive tasks and ensure consistency across experiments.

## Typical ML Pipeline

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Feature Selection
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. Hyperparameter Tuning
10. Model Deployment
11. Model Monitoring

## Why Use Pipelines?

* Reduces repetitive code
* Prevents data leakage
* Makes projects reproducible
* Simplifies deployment

## Applications

* Customer churn prediction
* Fraud detection
* Healthcare analytics
* Recommendation systems
