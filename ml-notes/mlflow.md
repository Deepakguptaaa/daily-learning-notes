# MLflow

## What is MLflow?

MLflow is an open-source platform used to manage the complete machine learning lifecycle.

It helps data scientists track experiments, manage models, compare results, and deploy machine learning models efficiently.

## Why Use MLflow?

* Tracks experiments automatically
* Stores model versions
* Compares different training runs
* Simplifies model deployment
* Supports collaboration within teams

## Components of MLflow

### 1. MLflow Tracking

Records parameters, metrics, and model artifacts for every experiment.

### 2. MLflow Projects

Packages machine learning code so it can be reproduced anywhere.

### 3. MLflow Models

Provides a standard format for saving and serving machine learning models.

### 4. MLflow Model Registry

Stores and manages different versions of trained models.

## Advantages

* Improves experiment management
* Makes projects reproducible
* Supports many ML frameworks
* Easy integration with Scikit-learn, TensorFlow, and PyTorch

## Applications

* Model experimentation
* Team collaboration
* Model versioning
* Production deployment
